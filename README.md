# 梨响 ROC · 客户奖励发放系统

微信小程序 + 微信云托管后端 + 微信支付「商家转账」，把奖励发到外部客户的微信零钱。
面向**企业微信客户的定向、批量奖励发放**：运营在小程序工作台里选客户、逐人给金额、群发通知，
客户打开小程序按身份自动看到属于自己的奖励并领取到账。**全程免国内服务器；企微直连需一个已备案的自定义域名。**

> 2025 新规：商家转账必须收款人自己点「确认收款」，微信不会主动推送到账，所以必须有一个小程序当"确认载体"。本系统按新规实现。

**当前状态**：核心链路（发钱 → 领取 → 确认收款 → 到账）已在生产跑通真实转账；企业微信客户联系已连通；
额度台账、撤回回流、客户等级、自动对账、公网防护均已上线并通过三层测试。构建标记 `p4-ledger-pro`。

## 一、功能全景

### 发放（运营侧 · 小程序工作台）
- **定向批量**：从企微同步客户 → 按备注名搜索 → 勾选一批 → **逐人不同金额/备注** → 提交
- **发放前总额确认**：弹窗过目「共 N 人 · 合计 ¥X · 最大单笔 ¥X」，额度不足再加硬提醒；按钮防连点（杜绝重复打款）
- **链接快发**：生成不记名领取卡片，转发即领（适合企微外临时发放）
- **群发通知**：企微群发一张**可点的小程序卡片**（员工在群发助手点一次发送），客户点卡片直达领取页
- **员工管理**：超管加/删发放员、分配角色（super / operator）

### 领取（客户侧 · 小程序）
- **定向身份识别**：客户打开小程序，后端用 unionid 认出本人，**只显示属于自己的奖励**，别人看不到、领不走（防领错）
- **到账仪式感**：确认收款成功后金额数字滚动、描边画勾、色块呼吸（纯 CSS/JS，守设计约束）
- **客户等级记录池**：按真实到账次数/累计金额分级（初识→新伙伴→熟客→金牌→钻石），开屏无奖励时与领取页都展示「合作 N 次 · 累计 ¥X · 距下一级还差…」
- **确认页手滑重开**：确认收款弹窗被误关后，再点「领取」可重新拉起确认，不再卡死在途转账

### 台账（对账后台 · 工作台「记录」页）
- **可发额度**（运行式余额，**不依赖微信余额接口、无需申请权限**）：「充值」累加携带上期结余、「校准」设为账户实际余额；数据库事务保证多管理员并发不丢笔
- **筛选**：状态（待领取/待确认/已到账/失败·撤回）× 时间（近 7/30 天）× **单人往来**（点客户名只看该客户）
- **汇总同口径**：筛选范围内的合计、实际动账、已到账/待确认笔数
- **撤回资金回流**：未领取的直接作废；已领取待确认的**调微信撤销转账 API，冻结资金退回商户余额**；台账标「已撤回」，可发额度自动回流
- **分页**、**发放人可追溯**（每笔显示谁发的）

### 可靠性 / 安全
- **自动对账**：后台每 10 分钟把在途转账向微信查最新状态回写——没配回调、回调丢失、落库缺笔都能自愈
- **幂等**：`out_bill_no = 奖励 rid`，重复领取不重复付款；到账 SUCCESS 状态钉死不被回退
- **best-effort 落库**：数据库抖动不阻断发钱/领钱；关键记账（CLAIMED）同步重试
- **公网域名防护**：公网自定义域名只放行回调/健康/验证路径，且不信任伪造的 `x-wx-openid`，防止从公网冒充管理员
- **金额规则前置**：≥2000 元必填真实姓名、<0.3 元禁填姓名、金额上下限——都在**生成时**拦截，不拖到客户领取才报错

## 二、架构

```
微信小程序（梨响ROC，微信开发者工具上传）
   │  wx.cloud.callContainer（平台注入可信 x-wx-openid / x-wx-unionid）
   ▼
微信云托管 · Node/Express 后端（本仓库根目录，监听 3000）
   ├── 内网 → 云托管自带 MySQL（库 rocpay，6 张表启动自动建）
   ├── 外网 HTTPS 签名 → 微信支付 V3 商家转账 transfer-bills / cancel / 查单
   └── 外网 HTTPS → 企业微信 客户联系 API（拉客户/unionid定向/群发）
        ▲
自定义域名 roc.bywood.com.cn（已备案，绑云托管）
   └── 仅承载回调：微信支付 /api/notify、企微 /api/wecom/callback、安全医生 verify 文件
```

- **小程序 ↔ 后端**：走云托管内网 callContainer，身份头由平台注入、不可伪造
- **回调/外部验证 ↔ 后端**：走公网自定义域名（企微/安全医生要求域名已 ICP 备案且主体与企业一致）
- 两条入口是同一个 Express；公网入口由 `WX_PUBLIC_HOSTS` 收紧为只放行回调路径

**技术栈**：Node 22 / Express（ESM）· mysql2（连接池 + 事务）· 原生 `crypto`（微信支付 V3 签名/AES-GCM/RSA-OAEP、企微 WXBizMsgCrypt）· 微信小程序原生（WXML/WXSS/WXS）。无重型框架。

## 三、数据模型（MySQL · 启动自动建表，幂等）

| 表 | 作用 |
|---|---|
| `rewards` | 发放的奖励（金额/备注/收款人姓名/定向目标/状态 CREATED·CLAIMED·SUCCESS·FAIL·CLOSED·CANCELLED） |
| `transfers` | 实际发起的转账（微信单号/状态/package_info；`out_bill_no=rid` 幂等） |
| `notify_events` | 微信回调审计流水（解密原文存档） |
| `admins` | 员工/管理员（openid / 备注名 / 角色 super·operator / 启用位） |
| `customers` | 企微客户缓存 + 身份映射（备注名搜索 / unionid 定向桥 / openid 回填） |
| `settings` | 通用键值（可发额度锚点 `quota_base_fen` / 锚点已发放 `quota_base_paid_fen`） |

DDL 见 [`db/schema.sql`](./db/schema.sql)（与 `src/db.js` 中的建表语句保持一致）。

## 四、接口一览（`src/app.js`）

| 方法 路径 | 说明 | 鉴权 |
|---|---|---|
| `GET /api/health` | 健康 + 构建标记 + db/企微/回调就绪位 | 公开 |
| `GET /api/me` | 当前身份 + 金额上下限 + **客户等级档案 profile** | callContainer |
| `GET /api/diagnose?key=` | 部署自检（证书/私钥/出口IP白名单） | `?key=` 恒定时间比对 |
| `POST /api/rewards` | 链接快发生成 | 管理员 |
| `POST /api/rewards/batch` | 定向批量发放（逐人金额） | 管理员 |
| `POST /api/rewards/revoke` | 撤回（未领取作废 / 待确认撤销回流） | 管理员 |
| `GET /api/rewards?status=&days=&target=` | 台账列表 + 同口径汇总（筛选/分页） | 管理员 或 `?key=` |
| `GET /api/period` · `POST /api/period/adjust` | 可发额度查询 / 充值·校准（事务） | 管理员 |
| `GET /api/customers` · `POST /api/customers/sync` | 客户搜索 / 企微同步（分批续传） | 管理员 |
| `POST /api/deliver` | 企微群发小程序卡片 | 管理员 |
| `GET/POST /api/admins` · `POST /api/admins/remove` | 员工列表 / 加员工 / 移除 | 超管 |
| `GET/POST /api/claim/mine` | 客户按身份查/领定向奖励（防领错） | callContainer |
| `POST /api/claim` | 令牌领取（快发卡片） | 令牌 HMAC |
| `GET /api/transfers/:outBillNo` | 查单并回写状态（对账） | 管理员 或 `?key=` |
| `POST /api/notify` | 微信支付回调（验签 + 落库，失败回 FAIL 让微信重试） | 签名 |
| `GET/POST /api/wecom/callback` | 企微接收消息回调（验签解密，用于解锁企业可信IP） | 企微签名 |

## 五、部署

完整分步走查见 **[`DEPLOY.md`](./DEPLOY.md)**。最小闭环：

1. 代码推 GitHub → 云托管绑仓库自动构建（端口 **3000**）
2. 云托管开 MySQL（同环境）→ 填 `MYSQL_*`（表自动建）
3. 填微信支付凭证（见《环境变量》），出口 IP 加进商户平台接口白名单
4. **公网防护**：`WX_PUBLIC_HOSTS=roc.bywood.com.cn,<云托管默认域名>`（强烈建议）
5. 小程序：微信开发者工具改 `config.js`（环境ID/服务名）→ 上传 → 体验版 → 提交审核发布
6. **企微直连**（P2）：需备案自定义域名绑云托管 → 配企微回调解锁企业可信IP → 填 `WECOM_*`，详见 DEPLOY §12

环境变量清单见 [`.env.example`](./.env.example)（真实值填在云托管「环境变量」，**不要提交 `.env`**）。
